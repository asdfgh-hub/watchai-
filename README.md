# WristAI (starter build)

Русскоязычное companion-приложение iPhone + Apple Watch. Проект собирается в GitHub Actions на macOS 26 / Xcode 26; локальный Xcode на Intel Mac не требуется.

## Что включено в этот первый исходный пакет

- iPhone: настройки Claude API, модель, общий промпт, количество последних фото (1–10), история запросов.
- Apple Watch: две основные кнопки; голосовая кнопка сразу вызывает системный контроллер диктовки WatchKit без промежуточной формы; экран ответа прокручивается Digital Crown.
- WatchConnectivity: передача запросов с часов на iPhone и ответов обратно.
- Claude Messages API: отдельный запрос на каждую фотографию, параллельность ограничена двумя задачами. Используется актуальная версия API `2026-10-21`; при необходимости можно задать Workspace ID.
- История хранится локально на iPhone.
- API key хранится в Keychain с доступом после первой разблокировки устройства.
- Приложение не воспроизводит звук и не озвучивает ответы.

## Сборка

1. Создайте пустой GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте вкладку **Actions** и запустите **Build WristAI** (или сделайте push в `main`).
4. Скачайте `WristAI-unsigned-ipa` из Artifacts.

## Важные ограничения первой версии

- HTTP 403 от Claude API не исправляется только интерфейсом приложения: для `permission_error` нужно проверить доступ ключа/Workspace в Claude Console; если ключ не привязан к одному Workspace, укажи его ID в настройках. При HTML/Cloudflare 403 проверь доступность сети и региона. Список поддерживаемых регионов: https://platform.claude.com/docs/en/api/supported-regions. Приложение теперь показывает тип ошибки и Request ID, если сервер его прислал.
- Это исходный MVP, а не проверенный на физическом устройстве релиз. GitHub Actions должен подтвердить, что Xcode 26 собрал проект; после этого потребуются правки по реальным логам сборки/установки.
- `macos-26` — Apple Silicon runner GitHub Actions. Это не зависит от Intel MacBook пользователя.
- Неподписанный IPA сам по себе не устанавливается. Его нужно переподписать бесплатным Apple ID. Способ установки именно embedded watch app нужно проверить на паре iPhone/Watch: сторонние sideload-инструменты могут по-разному обрабатывать Watch-компонент.
- iOS может приостанавливать приложение в фоне. WatchConnectivity умеет будить companion app для некоторых событий, но гарантировать выполнение произвольного долгого запроса при заблокированном iPhone нельзя. Если система не даст доступ к Photos или сети, приложение покажет ошибку на часах.
- Перед первым использованием нужно один раз открыть приложение на iPhone, сохранить Claude API key и выдать доступ к медиатеке. Это также позволяет пройти системные запросы разрешений до фонового использования.
- Для диктовки на часах используется стандартное поле ввода watchOS; пользователь нажимает микрофон в системной клавиатуре и подтверждает текст.

## Bundle IDs

- iOS: `com.wristai.app`
- watchOS: `com.wristai.app.watchkitapp`

Если эти идентификаторы уже заняты в вашем Apple ID, поменяйте их в `project.yml` и в workflow перед сборкой.

## Первичная настройка на iPhone

1. Открой приложение после установки.
2. Вставь Anthropic API key и нажми «Сохранить API Key».
3. Нажми «Разрешить доступ к фотографиям» и выбери полный доступ (либо ограниченный доступ с включёнными нужными фото).
4. Нажми кнопку обновления рядом с моделью и выбери модель из списка, возвращённого Anthropic API.
5. Настрой общий промпт и количество последних фото.
6. Открой приложение WristAI на Apple Watch и проверь связь.
